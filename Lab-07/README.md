# Lab 07 – EventEmitter and Event-Driven Programming

**Course:** CS403NOD – Node.js
**Semester:** BCA VII
**Lab Number:** 07
**Date:** 03 October 2026

## Objective

To understand EventEmitter and event-driven programming in Node.js by creating custom events, registering multiple listeners, handling errors, extending EventEmitter with classes, and developing a real-time order tracking system.

## Files and Their Purpose

* **events-basic.js:** Demonstrates creating and triggering a custom event using EventEmitter.
* **order-system.js:** Demonstrates multiple independent listeners responding to a single event.
* **once-vs-on.js:** Explains the difference between `.once()` and `.on()`.
* **error-handling.js:** Demonstrates safe handling of the special `error` event.
* **notification-center.js:** Demonstrates extending EventEmitter using a custom class.
* **order-tracker.js:** Combines event-driven programming concepts in a simulated order tracking system.

## How to Run

Open the terminal in the Lab-07 folder and run the files individually:

```bash
node events-basic.js
node order-system.js
node once-vs-on.js
node error-handling.js
node notification-center.js
node order-tracker.js
```
